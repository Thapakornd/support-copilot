# Published-knowledge chat implementation plan

Implement the [chat specification](../specs/2026-11-24-rag-chat.md) with Python, FastAPI, psycopg, LangChain and React. For each slice, run its focused failing test, implement the smallest working behavior, then rerun and refactor.

1. Define evidence, generation results and answer types in the domain and ports. Exercise the answer use case with fake retrieval, encoder and model dependencies.
2. Implement structured generation in the LangChain adapter. Test evidence delimiting, malformed output, invalid references, abstention and provider errors.
3. Implement read-only publication retrieval in PostgreSQL, including category normalization and model compatibility. Exercise replacement and filtering using the integration fixtures.
4. Wire configuration and bootstrap, then extend the HTTP schema and error mapping. Test via the FastAPI route with dependency overrides.
5. Update the Ask flow and case draft to use server citations. Exercise live success, abstention and failure. Build and lint the frontend.
6. Run the backend suite, frontend checks, and review the changes against the workflow diagram. Record any environment-dependent checks.
