# Published-knowledge chat

Implement the single-turn [chat workflow](../../../backend/docs/rag-chat.md). A user asks one support question and receives either a grounded answer with clickable evidence, a clarifying question, or an explicit service error.

## Serving contract

Keep POST /chat and the question/category inputs. Accept category IDs, legacy display labels and null. Reject unknown categories and blank or over-limit questions with 422. Search only active documents' current ready publications for the configured embedding model, category and compatible embedding configuration. Encode the question with the worker's pinned query encoder, rank by cosine distance, discard weak or duplicate passages and bound the evidence budget. Skip generation when evidence is empty.

LangChainLLM.answer(question, passages) returns structured cited steps or an abstention. System instructions distinguish quoted evidence from instructions. Validate every step and resolve its request-local IDs against the supplied passages. Reject unsupported citations and construct references exclusively from stored metadata. Number distinct sources by first use. A malformed or unavailable provider produces an upstream error. Set an explicit timeout.

Return answer, status (answered or insufficient_evidence), and sources. Each source contains number, document_id, revision_id, chunk_set_id, chunk_id, title, heading_path and source_url. An abstention has no sources. The Ask page renders all cited sources, validates HTTP(S) links, preserves cited document identities in case drafts, and supports retry on service failures. Keep related articles independent.

## Acceptance

Cover question/category validation, publication replacement, inactive and incompatible candidates, weak evidence with zero model calls, model abstention, missing and fabricated citations, provider failures and displayed source order. Use deterministic model doubles and a PostgreSQL integration fixture. Runtime database and model credentials stay local. The embedding worker remains responsible for publication.
